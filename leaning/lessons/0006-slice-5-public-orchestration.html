Lesson 6 · about 30 minutes

Connect the public round trip

Slice 5 does not invent another parser or ZIP writer. It connects the trusted blocks from Slices 1–4, keeps the source archive opaque, and returns success only after reopening and verification.

Your tangible win: implement the four public functions in round-trip.ts by connecting small responsibility blocks, without receiving a paste-ready implementation.

1. Slice 5 is orchestration, not new domain logic

The validator already owns the supported model rules. The codec already owns COLMAP text. The archive adapter already owns ZIP inventory and copy-through. The comparison functions already own model equality. Slice 5 decides when those operations run and what must be true before public success is returned.

ZIP bytes→ dataset→ verified ZIP bytes

Read

Open, parse, validate, resolve, and retain the source inventory.

Summarize

Derive counts and image ID 1 from the typed model only.

Write

Validate, resolve, serialize, copy, reopen, and compare.

Round trip

Reuse read, summary, and write; add strict no-op evidence.

Do not call zip.js or parse text directly from round-trip.ts. Doing so creates a second implementation of a responsibility that already has one owner.

2. Understand the two kinds of state in a dataset

RecorderDataset deliberately travels as a pair. The editable model contains understood COLMAP values. The opaque sourceArchive carries everything else needed to preserve the recorder ZIP: images, directories, actions, session data, and unknown files.

Part Consumer may do Consumer must not do
model Inspect it and later provide an edited valid model. Expect it to contain opaque ZIP entries.
sourceArchive Pass it back through the dataset to the writer. Construct, inspect, or rewrite its internal inventory.

The unique symbol property makes the public source type nominal enough that an ordinary object literal cannot accidentally satisfy it. TypeScript documents that every unique symbol has its own identity. This is compile-time encapsulation, not a security boundary: a forced type assertion can still bypass it. 

public view:   RecorderArchiveSource
private view: public brand + OpenedRecorderArchive

read creates the private value
write unwraps it internally
package consumers see only the public view

Keep the assertion, if one is needed to bridge those views, in one tiny private helper. Scattering casts through the workflow would make it unclear which code is allowed to create archive sources.

3. Block A — map between two existing representations

The adapter identifies sparse files by full ZIP paths. The codec names its three payloads cameras, images, and points3D. Slice 5 needs two explicit mappings; it does not need a generic mapper or a new abstraction.

Archive key Codec field
sparse/0/cameras.txt cameras
sparse/0/images.txt images
sparse/0/points3D.txt points3D

Make the mapping visible and boring. It is only three assignments. A loop that guesses names from strings saves little and makes a typo or later rename harder to notice.

4. Block B — read one recorder ZIP

readRecorderZip is a short pipeline. Each call hands its result to the next owner; no step repairs input or catches an expected ColmapError merely to hide it.

  1. Ask the archive adapter to open and validate the ZIP inventory.
  2. Map its three text byte arrays into the codec input shape.
  3. Parse them; the codec invokes model validation before returning.
  4. Resolve every parsed model image against the opened archive.
  5. Return the model plus an opaque wrapper around that same archive.

Image resolution belongs in the read operation even when the caller only wants the model. A syntactically valid images.txt that references absent image bytes is not a valid recorder dataset.

Do not return the resolved-image array publicly. Its successful creation is evidence that every reference exists; the model and source archive are the stable public seam.

5. Block C — derive the assignment summary

The summary must come from the typed model, never from comment headers, ZIP order, filenames, or the first image in an array. Validate the public model, then explicitly search for the record whose imageId === 1. 

selected image ≠ images[0]
selected image ≠ lowest image ID
selected image = image whose ID is exactly 1

JavaScript's Array.prototype.find returns undefined when no record matches. That missing branch must throw ColmapError with kind: "reference" and field: "imageId"; do not silently substitute another image.

Summary field Source of truth
imageCount model.images.length
point3DCount model.points3D.length
camera The validated single supported camera
image1 The exact ID-1 record
referencedImageCount The validated model image count

6. Block D — write and verify a supplied model

writeRecorderZip accepts a source dataset and a model as separate values on purpose. A later refiner may provide an edited model while the original source archive still supplies every opaque entry.

  1. Validate the supplied model at the public boundary.
  2. Unwrap the source archive inside the module.
  3. Resolve every supplied model image against that source.
  4. Serialize all three COLMAP text payloads with the real codec.
  5. Map them to the three exact replacement paths.
  6. Ask the adapter to copy the complete archive with replacements.
  7. Reopen the output through readRecorderZip.
  8. Require semantic equality with the model that was supplied.
  9. Return bytes only after every previous step succeeds.

The equality target is the supplied model, not necessarily source.model. Comparing only with the original would make every legitimate future pose edit fail. The strict unchanged-model check belongs to roundTripRecorderZip instead.

Never return bytes before reopening. A writer producing bytes proves neither that the ZIP can be read nor that its generated COLMAP text can be parsed and resolved.

7. Block E — turn comparison results into a gate

The comparison functions return a discriminated union. They do not throw. Narrow on equal; only the false branch exposes path and reason. This is the same discriminated-union narrowing used earlier in Slice 3. 

comparison = compare(expected, reopened)

if comparison.equal is false
  path and reason are available
  throw the shared contextual error

otherwise
  the guarantee may be recorded as literal true

A verification object contains literal true fields because it is returned only after the corresponding checks pass. It is a proof record, not a live collection of uncertain booleans.

8. Block F — verify archive preservation by identity

Model comparison cannot prove that actions/, an unknown binary file, or an unreferenced image survived. Compare the private opened inventories from the source and reopened output by exact path.

Entry group Required check
Every path Same exact path set and same file/directory kind.
Three sparse text files Bytes equal the corresponding actual serializer payload.
Every other file Decompressed bytes are exactly equal to source bytes.
Directories The explicit record still exists with directory kind.

Index by path so ZIP entry order is irrelevant. Compare Uint8Array contents, not object identity: two arrays may contain identical bytes while left === right is false. A short length check followed by an indexed byte loop is sufficient; no Node Buffer and no deep-equality library are needed.

9. Block G — the no-op round-trip demonstration

roundTripRecorderZip must reuse the three public operations instead of recreating their internals. Its special job is to run them with the unchanged model and add stricter acceptance evidence.

  1. Read the input bytes into one dataset.
  2. Summarize that typed model.
  3. Write using the same dataset and unchanged dataset.model.
  4. Reopen the emitted bytes for verification.
  5. Require exact no-op model preservation.
  6. Verify path, kind, replacement, and untouched-entry guarantees.
  7. Return the dataset, summary, bytes, and all-true proof record.

Semantic equality is necessary in general writing. Exact preservation is additionally valid here because this operation intentionally made no model edit. Keep both concepts visible: semantic equality treats q and -q as the same orientation, while the exact no-op check detects a changed quaternion representative.

10. Tests should prove wiring, not repeat lower-level suites

Keep the Slice 5 test fixture synthetic and complete enough to exercise the real components. You do not need to duplicate every parser token or unsafe-path case from earlier slices.

  1. readRecorderZip returns the parsed model and rejects a missing referenced image.
  2. Summary counts come from model arrays even when ZIP comments or entry order suggest something else.
  3. The ID-1 image is selected even when it is not first.
  4. Missing image ID 1 produces the required reference failure.
  5. A noncanonical valid input emits all three canonical serializer payloads, proving original text was not copied through.
  6. The emitted bytes reopen before the write promise resolves.
  7. The reopened model is semantically equal to the supplied model.
  8. The unchanged round trip is also exactly preserved.
  9. Paths and kinds match; all untouched decompressed bytes match; the replacement set is exactly the three sparse text paths.
  10. The public ./colmap entry exports only the intended public types, functions, error, and comparisons.
  11. Core files have no node:*, Buffer, filesystem, or process usage.

The strongest “writer really ran” fixture starts with valid but noncanonical sparse text: different comments, spacing, numeric lexemes, or CRLF endings. The parsed meaning stays the same, but each output sparse payload must equal the canonical serializer result and differ from the appropriate original bytes.

11. Keep Slice 6 and later work out

Slice 5 remains browser-compatible and entirely in memory. Do not add CLI argument parsing, node:fs, temporary files, final renames, console formatting, real Task 1 fixture replay, LichtFeld, or AppFramework integration. Those have their own slices and failure policies.

You also do not need dependency injection, a factory, or mock adapter interfaces for this slice. The existing functions and one adapter object already provide the required seams; integration-style synthetic tests are the point.

Your first implementation step

Create round-trip.test.ts with one valid synthetic ZIP. First test only readRecorderZip: assert the known model and prove an unreferenced image does not cause rejection. Then add the summary ID-1 case. Connect writing only after those two blocks are green.
