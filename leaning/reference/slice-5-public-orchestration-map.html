Public round-trip map

Connect the existing owners, preserve the opaque source, and return success only after reopening and verification.

Ownership rule

Component Slice 5 calls it for
Validator Trusting public model input.
Text codec Parsing and serializing the three COLMAP texts.
ZIP adapter Inventory, image resolution, copying, and replacements.
Comparisons Semantic write verification and exact no-op verification.

Public operations

Operation Required sequence
readRecorderZip Open → map texts → parse/validate → resolve → dataset.
summarizeRecorderModel Validate → derive counts/camera → find exact image ID 1.
writeRecorderZip Validate → resolve → serialize → copy → reopen → semantic check.
roundTripRecorderZip Reuse read/summary/write → reopen → exact/archive checks → result.

Dataset seam

RecorderDataset
├─ model          editable, understood COLMAP values
└─ sourceArchive  opaque, pass-through archive inventory

Only the read operation creates the opaque source. The writer uses it internally so unknown files, images, actions, and directories survive.

Summary source of truth

  • Counts come from typed model array lengths.
  • Camera comes from the validated single-camera model.
  • Selected pose comes from imageId === 1.
  • Never use comment counts, ZIP order, or array position.
  • Missing ID 1 is a contextual reference failure.

Archive verification

  • Reopen the produced bytes through the public read path.
  • Same exact entry path set and kind per path.
  • Exactly three replacement paths.
  • Selected bytes equal actual serializer payloads.
  • Every untouched decompressed payload is byte-identical.
  • Compare byte contents, not Uint8Array identity.

Test signal

Use valid noncanonical input text. If the output contains the canonical serializer bytes at all three sparse paths, the public path cannot have passed by copying the original text.

Do not add

No second ZIP reader/writer, second text parser, dependency-injection framework, Node filesystem, Buffer, CLI paths, temporary files, real fixtures, LichtFeld, or AppFramework integration.
