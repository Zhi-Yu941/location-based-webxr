Explicit directory

await zipWriter.add("sparse/", undefined, { directory: true });

Keep the trailing slash in the path and set directory: true. On read, trust entry.directory; do not infer the kind only from the slash.

Safe inventory branch

const item = entry.directory
  ? {
      path: entry.filename,
      kind: "directory" as const,
      bytes: new Uint8Array(),
    }
  : {
      path: entry.filename,
      kind: "file" as const,
      bytes: await entry.getData(new Uint8ArrayWriter()),
    };

Close both layers

const zipBytes = await zipWriter.close();
await zipReader.close();

ZipWriter.close() finalizes the central directory. A writer result before finalization is not a complete ZIP.

Assertions that match the contract

  • Compare path sets, not entry order.
  • Compare kind separately from payload length.
  • Compare decompressed Uint8Array values with deep equality.
  • Use one non-text binary payload such as [0, 255, 1, 128].
  • Keep an empty file in the fixture; zero bytes must not mean “omit entry.”
  • Reopen the output ZIP before making preservation claims.
Do not compare: complete ZIP bytes, compressed entry bytes, order, timestamps, compression level, comments, or unrelated metadata.
