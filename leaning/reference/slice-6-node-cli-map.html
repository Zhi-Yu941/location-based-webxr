Safe Node CLI map

One thin filesystem/process wrapper around the compiled, verified browser-compatible core.

Dependency direction

scripts/colmap-round-trip.mjs
  → ../dist/colmap/index.js
  → roundTripRecorderZip(Uint8Array)

never import src/*.ts directly
never parse COLMAP or ZIP inside the CLI

Success transaction

  1. Require exactly two user arguments.
  2. Resolve input and output to absolute paths.
  3. Validate input, output parent, and output absence.
  4. Read input bytes.
  5. Await the compiled round-trip orchestrator.
  6. Write verified bytes to a unique temporary sibling.
  7. Rename temporary sibling to the final output.
  8. Print summary and resolved output path.

Path policy

State Decision
Input and output resolve to the same path Fail
Input missing, unreadable, or not a file Fail
Output parent missing or not a directory Fail; do not create it
Final output already exists Fail; do not overwrite it
All checks and in-memory verification pass Publish through sibling rename

Failure invariant

  • Input bytes remain unchanged.
  • No successful final output path is created.
  • Known temporary sibling removal is attempted.
  • Cleanup does not hide the original failure.
  • Concise diagnostic goes to stderr.
  • process.exitCode becomes non-zero.

Subprocess test oracle

  • Build before launching the CLI.
  • Use process.execPath and an argument array.
  • Keep shell execution disabled.
  • Assert status, stdout, stderr, and filesystem state.
  • Use a unique operating-system temporary test directory.
  • Reopen successful output through the compiled public core.
  • Assert input/existing-output preservation and temp cleanup.

Minimum cases

Wrong argument counts; equal paths; missing/non-file input; missing output parent; existing output; invalid ZIP; missing image ID 1; successful synthetic ZIP; image ID 1 not first; no leftover temporary file.

Do not add

No CLI framework, flags, prompts, directory creation, output overwrite, direct source import, duplicate parsing/ZIP logic, real Task 1 fixtures, LichtFeld, progress UI, or AppFramework integration.
